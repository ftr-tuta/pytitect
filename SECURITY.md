# Security policy

The latest prerelease receives security fixes. Until 1.0, older prereleases are not supported.

Please report a suspected vulnerability privately through GitHub's security advisory form. Include
the affected version, a minimal reproduction, impact, and any suggested mitigation. Do not include
real credentials or production data. You should receive an acknowledgement within seven days.

Pytitect supplies verification primitives, not application authorization. Consumers are responsible
for secure key resolution, tenant and database selection, TLS, secret storage, and authorization.
